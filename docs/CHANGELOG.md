# 更新日志

本文档记录 MDM 主数据管理系统从项目启动至今的所有版本迭代。

---

## v1.3.0 (2026-05-29) - 功能补齐与优化

### 新增

- 多角色权限支持（运维管理员 / 数据管理员 / 审核人 / 申请人 4 种角色完整联调）
- 全局菜单搜索功能（模糊匹配 + 键盘操作 + Ctrl+K 快捷键）
- 菜单配置页面改造为树形表格（目录 / 菜单 / 按钮分色标签）
- 新增 6 个功能页面：
  - 模型审核（ModelAudit）
  - 分类配置（CategoryConfig）
  - 数据接收（DataReceive）
  - 查询服务（DataQueryService）
  - 密级配置（SecurityLevel）
  - 系统监控（SystemMonitor）
- 权限矩阵扩展至 76 个权限码
- 管理中心后端 API 补齐（用户角色分配接口）
- 个人中心与修改密码页面

### 优化

- UI 全局颜色柔和化（30+ 组件覆盖）
- 数据导入 / 导出功能增强
- ESB 定时调度服务

### 修复

- 数据库乱码数据清理修复
- 非管理员用户 Access Denied 问题修复
- BaseUser 实体 SECURITY_LEVEL 字段映射错误修复

## v1.2.0 (2026-05-xx) - 系统深度完善

### 新增

- RBAC 权限体系（角色 / 菜单 / 按钮三级权限控制）
- 工作流引擎（流程定义、节点配置、任务审批、转办 / 认领 / 会签）
- ESB 数据交换（分发配置、分发监控、服务编排）
- 安全加固（SpEL 注入防护、SQL 参数化查询、XSS 过滤）
- 前端深色科技主题 UI 重构
- 登录态双校验机制（Token 存在性 + 时效性双重验证）
- 数据字典管理模块
- 系统参数管理模块
- 系统设置页面
- AOP 审计日志切面
- JwtTokenEnhancer 令牌增强

### 优化

- Spring Security 配置完善，按角色限制 API 访问
- 数据权限切面（DataScope 注解 + DataScopeAspect）

### 修复

- Entity 字段映射与数据库列名一致性修复
- 前端路由守卫 Token 时效性校验修复
- API 端点前后端对齐修复

## v1.1.0 (2026-04-xx) - 核心业务功能

### 新增

- 数据模型管理（创建、编辑、发布、可视化设计器）

- 数据申请与审核流程
- 数据归档管理
- 数据分发与监控
- 审计日志记录
- 用户管理、角色管理、组织管理、群组管理
- 菜单管理页面
- Dashboard 仪表盘

### 优化

- 前端路由懒加载
- API 层 Axios 统一封装与响应拦截
